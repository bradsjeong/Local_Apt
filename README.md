# 진주·거제 아파트 분석

지도 중심의 모바일 웹앱입니다. 실제 국토교통부 매매 신고 자료와 사용자 가정 시뮬레이션을 분리합니다. 가상 단지·가상 과거 가격은 포함하지 않습니다.

## 게시 및 수집 설정

1. 공공데이터포털에서 **국토교통부 아파트 매매 실거래가 자료** 활용신청을 승인받습니다: https://www.data.go.kr/data/15126469/openapi.do
2. 저장소 **Settings → Secrets and variables → Actions → New repository secret**에서 `MOLIT_SERVICE_KEY`에 일반 인증키(Decoding)를 등록합니다. 공개 파일에 인증키를 쓰지 않습니다.
3. **Settings → Pages → Build and deployment → Source: GitHub Actions**를 선택합니다.
4. **Actions → Collect data and publish Pages → Run workflow**를 실행합니다. 처음에는 2010년 1월부터 현재월까지 진주·거제를 모두 수집하므로 시간이 걸립니다.
5. 카카오 Developers에서 JavaScript 키의 허용 도메인에 `https://bradsjeong.github.io`를 등록합니다. 앱에서 카카오맵 사용이 활성화되어 있어야 합니다. 키는 `site/map-config.js`에서 변경합니다.

예상 Pages 주소: https://bradsjeong.github.io/Local_Apt/ (배포 성공 전에는 열리지 않습니다.)

매일 06:20 KST에 재수집·배포합니다. 전체 기간을 재조회하여 과거 해제·정정도 반영합니다. 키 누락, 수집 실패, 누락 페이지, 잘못된 필수값이 있으면 **배포를 중단하고 기존 게시본을 유지**합니다. 두 도시 수집이 모두 성공한 결과만 배포합니다. 공개 화면에는 키가 아닌 수집된 실거래 파일만 포함합니다. 워크플로 실행의 `official-data` 아티팩트에서 실제 수집본을 내려받을 수 있습니다.

## 데이터와 해석 범위

- 지역 코드: 진주시 48170, 거제시 48310. 기간: 2010.01~실행일의 현재월.
- API의 취소 표시 또는 해제일이 있는 거래는 제외합니다.
- 금액 원단위는 만원이며 화면에서 억원으로 변환합니다.
- 동일 이름이라도 법정동·지번·단지 식별 정보가 다르면 구분합니다. 같은 날짜·면적·가격의 서로 다른 거래를 임의 삭제하지 않습니다.
- 80~86㎡ / 55~65㎡ / 전체 면적으로 필터링합니다. 정확히 같은 면적·층·향을 통제한 시세가 아닙니다.
- 연도별 통계는 **㎡당 거래금액 중앙값**입니다. 공식 가격지수나 동일주택 상승률이 아닙니다. 5건 미만은 표시하지 않습니다.
- 최근월은 신고 중이며 자료는 정정될 수 있습니다. 조회 범위 최고 거래금액은 역대 최고가를 보장하지 않습니다.
- 실제 거래 주소를 카카오 주소검색으로 확인한 결과만 표시합니다. 임의 좌표로 대체하지 않습니다. 한 페이지 최대 30개 단지입니다.
- 신규 분양가, 입주, 미분양, 인구, 산업, 한국부동산원 가격지수, 전월세는 **아직 미연결**입니다. 임의 값으로 보충하지 않습니다.
- 보유주택의 가격 변화·임대차·36개월 경로는 **사용자 가정 계산**입니다. 매수·매도 추천을 제공하지 않습니다. 입력값은 저장하거나 서버로 전송하지 않습니다.

## 로컬 실행

Python 3.12 이상, 외부 패키지 불필요.

```sh
python -m unittest discover -s tests -v
# MOLIT_SERVICE_KEY 환경변수를 안전하게 설정한 후:
python scripts/collect.py
python -m http.server 8765 --directory site
```

키를 커맨드 인수로 넘기거나 커밋하지 마세요. JavaScript 카카오 키는 브라우저에 공개되는 종류의 키이므로 별도로 도메인을 제한합니다.
